  defective asset compiler. The iOS half landed at `566a584`; Android landed at
  `fd09fb8` after preserving non-rotated refresh tokens in Plan 004.

  `c4df344`. The workaround is validation-only; production project inputs and
  application behavior are unchanged.

  active deep audit is vetted. The user's accepted product plan is the locked
  direction; the audit exists to give each executor exact live paths, excerpts,
  tests, and STOP conditions rather than to reopen settled product choices.

  project skill root: rejected because official Codex behavior does not merge

- Creating a Wayfinder decision map for the accepted command-center rebuild:
  rejected because the destination, constraints, provider boundary, cloud
  choice, and implementation order are already decision-complete. The
  remaining work is execution planning, so it belongs in these Improve plans
  and implementation issues rather than artificial research/prototype tickets.
